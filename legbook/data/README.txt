airport-timezones.csv — the airport time-zone table used by the app Legbook: Pilot Logbook.

Columns: ident, icao, iata, gps, latitude, longitude, name, country, time_zone (IANA).

Sources:
- Airports (ident, codes, positions, names, countries): OurAirports, public domain (https://ourairports.com/data/).
- Time zones: mwgg/Airports (MIT License, Copyright (c) 2014 mwgg, https://github.com/mwgg/Airports), and for airports
  not found there, @photostructure/tz-lookup (CC0 1.0, https://github.com/photostructure/tz-lookup) on the coordinates.
